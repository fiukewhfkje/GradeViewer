# Portable Carmen VM diagnostic

**November 1, after 7 PM EST update:** two fresh separately authenticated owner captures are saved in persistent Mac storage, with a new private Muse bundle and [exact instructions](CARMEN_MUSE_HANDOFF.md). The original temporary archive below is historical/missing. The current runner establishes initial HTTP baselines on Muse's VM, then measures active/idle survival and actual Cloudflare recovery/budget using the VM's own authorized owner-account Wrangler login. No Mac Cloudflare OAuth credential is exported, no Canvas personal token is needed, and no VM install/cron is claimed. See [current paths/evidence](CARMEN_HANDOFF.md). Local-browser recovery remains an explicit alternative but cannot prove Cloudflare budget.

At the owner's explicit request, a private export of their own saved session and the diagnostic was prepared for Muse's separate VM. It is outside the repository; no credentials are embedded in a prompt, committed, or included in a public release. The export contains only the scoped OSU/Carmen/Duo session envelope, its private wrapping key and selected test sources. It contains no OSU password, Schoology credentials or Cloudflare account credentials. The original identity-only 48-hour test limit remains enforced.

The bundle uses the existing canonical profile validation, managed HTTP cookie jar, same-account checks, encryption and bounded SSO procedure. Its `run-check.sh` uses `check --consent --local-browser`: ordinary HTTP first, then the VM's own headless Chromium only on verified rejection. This requires Node 24+ and Playwright Core/Chromium setup on that VM. `CARMEN_CHROMIUM_PATH` can select an existing VM Chromium. No Wrangler login, Cloudflare token, Cloudflare browser minutes or recurring model calls are required. HTTP-only observation remains available with `--no-renew`.

This is an operator experiment; the production PWA remains independent of Muse. A local-VM browser result does not measure Cloudflare latency or establish production Worker/full-grade/phone acceptance. Moving the session to a new VM is an additional variable: Duo can apply endpoint/policy checks to remembered sessions, so an immediate human requirement after migration must not be attributed solely to elapsed time. [Duo remembered-device policy](https://duo.com/docs/policy).

For the initial idle test, leave this session untouched until the next morning, then make one check and record its actual gap. On success, a second check after a further 24 hours and five minutes can test a longer return, provided it remains within the original 48-hour test authorization. A deterministic cron may tick every minute but should only invoke HTTP at due phases. Stop on human attention/errors; never retry every minute, fill credentials/MFA or accept policies. Copies of one cookie file share a server session and are not independent idle trials; do not poll from Mac and VM in parallel. No new session/login was initiated during export.

Offline metadata inspection found that the saved Carmen cookies have no persistent expiry timestamp. Other cookie retention dates cannot establish the effective server/SSO/MFA lifetime. OSU documents [two-hour Carmen inactivity logout](https://it.osu.edu/news/2025/08/18/technology-updates-autumn-2025) and [24-hour BuckeyePass browser trust separately](https://it.osu.edu/security/services/buckeyepass). These are different layers, and neither is a universal unattended-login guarantee. An overnight failure bounds expiry rather than revealing the precise moment. Fresh independent trials around an expected threshold would be needed for a narrower estimate.

Export validation used only private local files and synthetic browser tests; no provider request or idle reset was made. The bundle's dependency/package layout, transferred-state loading, shell syntax and no-consent CLI guard were checked. Symlinked entry paths exposed a silent CLI no-op, fixed by canonical path comparison with a regression. The private archive was allowlisted/audited, with no `.env`, cached Wrangler login, node_modules or browser binary copied. The bundle is not installed or scheduled on Muse's VM by this task.
